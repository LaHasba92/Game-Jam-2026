# Game Jam 2026
# Canon POW

**Un tir, des murs en miettes, toujours plus loin.**

Jeu mobile hypercasual créé en 43 heures pendant la game jam
Voodoo x Gaming Campus (19–21 novembre 2026), sur le thème
« Physics-based destruction puzzles ».

![Aperçu du jeu](Docs/apercu.gif)

## Le jeu

Le joueur vise depuis un lanceur, lâche dans une jauge de puissance,
puis dirige son boulet en vol. Chaque mur touché en l'air explose,
et le boulet file vers le mur suivant, toujours plus loin.
Les pièces gagnées débloquent 5 lanceurs (de la fronde au canon)
et 5 améliorations.

## Contrôles

| Action | Mobile | PC |
| --- | --- | --- |
| Viser | Glisser le doigt | Clic maintenu + déplacer la souris |
| Tirer | Relâcher dans la jauge | Relâcher le clic |
| Diriger le boulet | Glisser en vol | Déplacer la souris |
| Passer la fin du vol | Bouton « Passer » | Espace |
| Pause | Bouton en haut à gauche | Échap |

## Lancer le projet

1. Installer **Unity 6000.3.21f1** (avec le module Android pour le build mobile).
2. Ouvrir le dossier du projet dans Unity Hub.
3. Ouvrir la scène `Assets/[chemin]/Game.unity`.
4. Appuyer sur **Play**.

Builds fournis : APK Android et version PC (fenêtre portrait 540 × 960).
